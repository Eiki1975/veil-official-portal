# VEIL 英語エピソード公開標準

- STATUS: ACTIVE OPERATING POLICY
- 制定日: 2026-08-02
- 適用開始: 雨宮玲奈 Season 01 第1話の英語版公開から

## 基本方針

各エピソードは、日本語版の公開と同時に、独立した英語ローカライズ版を別URLで公開する。

- 日本語と英語を同一本文へ併記しない。
- 英語版は逐語訳ではない。出来事、成人設定、同意関係、視点、人物関係、官能の心理的意味を守り、英語圏の成人向け心理・官能フィクションとして自然に読むことを優先する。
- 画像資産は日英で同じ公開URLを参照する。複製、再アップロード、英語専用の正本化はしない。
- 日本語正本は英訳作業で上書きしない。英訳は日本語正本へのsource hashを持つ独立ファイルとして保存する。

## 話ごとの公開条件

EP02以降を含め、各話ごとに次の条件がそろうまで公開を始めない。

1. 日本語本文の現行正本と公開承認がある。
2. 英語ローカライズ候補を別資産として作成する。
3. 英訳のセルフレビューで、出来事・時系列・成人設定・同意/非同意・限定視点・既存関係・文化語・英語の自然さを確認する。
4. 画像の英語alt/caption/本文アンカーを用意し、既存と完全に同じ画像URLを参照する。
5. 日本語URLと英語URLの相互切替、年齢表示、モバイル、直接アクセス、画像200を確認する。
6. ユーザーがその話の日英公開を明示承認する。

日本語正本の承認だけ、英訳候補の作成だけ、またはサイト実装だけでは公開承認にならない。

## URLと実装の標準

英語話数のURLは次を基準とする。

`/en/stories/{member}/season-{season}/episode-{episode}/`

日本語ページのタイトル付近には `日本語 / EN` の相互切替を置く。英語ページは静的HTMLとして直接200を返し、固有の `lang="en"`、canonical、ja/en/x-default hreflang、英語のtitle/description/OG、成人向け表示を持つ。

英語本文は `src/content/*-en-YYYYMMDD.md` の独立ソースから生成する。`tools/build-en-story-pages.mjs` の話数設定へ新規話を追加し、公開HTMLはビルド時に生成する。英語本文を日本語用 `serial-stories.json` に混ぜない。

日本語本文は初期JavaScriptへ混ぜない。`src/content/serial-stories.json` を正本に近い公開用ソースとして保持し、`tools/build-story-data.mjs` が話ごとの `/story-data/{story-id}.json` と軽量な `serial-stories-index.json` をビルド時に生成する。画面側はこの本文を含まない一覧だけを読み、年齢確認後に開いた話のJSONだけを取得する。

ローカル編集画面も、公開済みの記事を開くときに同じ話別JSONを読み込む。編集用コピーを「公開用に反映」したローカル開発中は、Viteのローカル編集機能が対応するJSONも更新する。生成済みの `public/story-data/` はビルド成果物であり、Gitには入れない。

## 検索・公開範囲

現在の成人向け本文ページは日英とも `noindex, nofollow` とする。検索掲載へ変える場合は、成人向け表示、各国向けの運用、SEO、利用規約を別途確認し、単独で承認を得る。

## 今回より後の扱い

この標準は将来運用のための設計である。EP02以降の本文作成、英訳作成、画像生成、実装、公開を自動的に開始する根拠にはならない。各話ごとの日本語正本と公開承認を待つ。
