# VEIL NOTES 公開方針

## 目的

`VEIL NOTES` は、作品世界内の記録とは区別された、非露骨な制作記録の連載です。

## 公開データ

- 公開対象は `src/content/notes-published/index.json` に明示された記事だけです。
- 本文は記事の `slug` と同名の `src/content/notes-published/{slug}.md` だけを読む固定方式です。
- 公開用 index には、下書き状態、候補ID、内部コメント、会話、プロンプト、任意の本文ファイルパスを入れません。
- ビルドは不明な項目、重複ID・slug、無効な日付や画像パスを検出すると停止します。

## 非公開データ

- 下書き、題材候補、会話、候補画像、承認メモ、制作ログは `.veil-admin/notes/` にのみ置きます。
- `.veil-admin/` は Git と公開サイトのビルド対象から除外されています。
- 過去の会話や候補を `notes-published` へ自動コピーする処理は作りません。

## 公開手順

1. 記事本文・公開要約・公開画像（使用する場合）を個別に確認する。
2. ユーザーから、その記事をサイトで公開する明示承認を得る。
3. 承認済みのコピーだけを `notes-published` へ新規追加する。下書きや既存原本は上書きしない。
4. NEWS 用の短い更新文を個別に用意し、ビルドとローカル確認を行う。
5. 公開操作は、記事承認とは別の明示承認後に行う。

設置承認は、将来の記事や候補の公開承認ではありません。
